# Machine-Learning-
Machine Learning (ML) is a branch of artificial intelligence (AI) that focuses on building systems that learn from data, identify patterns, and make decisions with minimal human intervention.

Machine Learning (ML) is a subfield of Artificial Intelligence where algorithms learn patterns directly from data to make predictions or decisions, rather than relying on explicitly programmed rules.

Main Types:
• Supervised Learning: Learns from labeled data to map inputs to target outcomes (e.g., classification, regression).
• Unsupervised Learning: Discovers hidden structures or clusters in unlabeled data (e.g., grouping customers, anomaly detection).
• Reinforcement Learning: Learns optimal actions through trial-and-error using a system of rewards and penalties (e.g., robotics, game AI).

Core Workflow:
Data Collection & Cleaning -> Feature Engineering -> Model Training -> Performance Evaluation -> Hyperparameter Optimization -> Deployment

Goal:
To create models that generalize well to new, unseen data without underfitting or overfitting.
